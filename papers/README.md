# AI4Math
An open mathematics website that combines blockchain technology with AI-powered proof verification, with a strong emphasis on validation and explanation. It features a free and open formal verification engine capable of rapidly determining the correctness of certain proofs. This platform empowers both mathematical researchers and enthusiasts to build and run minimum viable products (MVPs), thereby advancing the industrialization of mathematics.

## 项目愿景
结合区块链技术+AI证明的开放数学网站，侧重验证与解释，有一套开放而免费的形式化验证引擎，快速决断某些证明是否正确————可以助力数学工作者与数学爱好者跑最小mvp，助力数学工业化。
